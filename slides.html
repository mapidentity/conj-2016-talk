📂👀 something watches

(loop [seen (modified-times)]
  (Thread/sleep 200)
  (let [current (modified-times)
        changed (for [[path t] current
                      :when (and (not= t (get seen path))
                                 (watched? path))]
                  path)]
    (when (seq changed)
      (when (every? true? (mapv load-changed! (sort changed)))
        (socket/notify-reload!)))
    (recur current)))

> notify-reload! for every file changed in the last 200 milliseconds.

💌🌐 something tells the browser

(defonce clients (atom #{}))

(defn broadcast! [msg]
  (let [s (json/write-str msg)]
    (doseq [ch @clients]
      (http/send! ch s))))

(defn notify-reload! []
  (broadcast! {:type "reload"}))

(defn ws-handler [req]
  (http/as-channel req
    {:on-open  (fn [ch] (swap! clients conj ch))
     :on-close (fn [ch _] (swap! clients disj ch))}))

> uses org.clojure/data.json to send a websocket message with http-kit

Render erases the structure, on every request.

[:span.badge.hot "🌶 " t]  ─►  "<span class=\"badge hot\">🌶 spicy</span>"
 its line and column              …gone, and the class was never a string
  • React keeps a live component tree — its devtools just read it
  • we flatten our own data with our own render fn — for good reasons
  • what gets deleted by choice
    can be kept by choice

Three facts that make it a small tool

  • the default reader: (meta [:div …]) → nil
  • tools.reader: :line :column :end-line :end-column —
    on every nested vector
  • the compiler preserves a literal’s metadata
    onto the runtime value — even in loops

Load views through tools.reader → every element knows its source.
The position is part of the value.

The re-def that strips every tag

The tags exist only because the loader applied them.
A plain load-file — or your editor’s eval-on-save —
re-defs the views untagged. Silently.

The loader is the single source of truth
for how views load.

The moment there are two ways to load a thing, one of them is wrong.

Nothing ships

(def ^:dynamic *render-boundary* identity)        ; the app's one seam
(binding [views/*render-boundary* dev-body] …)    ; dev/, per request
  • no loader in prod → no metadata, no wrapping, empty index
  • overlay + agent + middleware live in dev/
  • a dev-only classpath: nothing binds the seam — structurally absent,
    not disabled
  • the reason we never had this — we throw structure away —
    is what keeps it safe in prod: there, we still do
